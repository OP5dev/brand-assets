# Brand Assets for [Noise Rest](https://noise.rest)

1. [Usage guide](exploration/14-usageguide.html): clear space, minimum sizes, colour versions, don'ts.
2. [`svg/noise-rest.svg`](svg/noise-rest.svg): the primary logo. Other versions are in [`svg/`](svg/).
3. [`design/tokens.json`](design/tokens.json): colours, font and logo geometry. Change the accent here, then run `python3 tools/outline.py` to rebuild `svg/`.
